# Lenovo-ThinkPad-P14s-Gen-1-macOS-Tahoe-26.7.3
OpenCore EFI for macOS Tahoe 26.7.3 on the Lenovo ThinkPad P14s Gen 1 (i7-10610U, UHD 630, AX201, ALC257). Dual-boots with Windows 11. Works: Wi-Fi, Bluetooth, audio, trackpad, sleep, lid, HDMI. APFS boot-trim patch gives a ~21 s boot. Not working: internal mic, NVIDIA GPU.
